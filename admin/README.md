# Owner Admin Dashboard

TeslaMarketplace is owner-controlled. This area is reserved for the platform owner/admin.

## Planned controls

- Inventory: create, edit, publish, hide, reserve, and mark sold
- Pricing: set and update sale prices
- Vehicle details: specifications, descriptions, photos, availability
- Customers: review buyer profiles and purchase requests
- Orders: confirm, process, fulfill, cancel
- Update monitor: review detected public-source changes before applying them

## Security requirement

Admin routes must be protected by real authentication and authorization before production use. Do not expose owner controls through an unprotected public route.

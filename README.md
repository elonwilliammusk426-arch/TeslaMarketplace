# Tesla Marketplace

Tesla-inspired vehicle marketplace prototype with a responsive inventory experience.

## Included

- Inventory browsing with New / Certified Pre-Owned tabs
- Model, price, year, mileage, condition and demo-drive filters
- Sorting by featured, price, mileage and year
- Vehicle cards with imagery, pricing and key specifications
- Vehicle detail modal with range, speed, acceleration, configuration and condition
- Responsive mobile layout
- Frontend-only demo data ready to be connected to a backend/database

## Run

Open `index.html` in a browser. No build step is required for the prototype.

## Next production layer

Connect the inventory objects to the marketplace database and API, then add authentication, seller listing creation, image storage, offers/orders, payments, delivery tracking and admin moderation.

This project is an independent marketplace concept and is not affiliated with Tesla, Inc. It uses a Tesla-inspired user experience rather than copying Tesla proprietary source code or branding assets.

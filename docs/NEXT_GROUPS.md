# Remaining Product Groups

## Locked included groups
- Mobile app
- International / multi-currency
- Charging / energy products

## Locked excluded groups
- Trade-in
- Financing integration
- Insurance
- Service scheduling
- SMS notifications
- Live delivery map
- Third-party sellers / peer-to-peer marketplace

## Build sequence
1. Complete core owner-sales flow and order administration.
2. Build the three included expansion groups: mobile app, international/multi-currency, charging/energy.
3. Run integration and production-readiness checks across the whole system.
